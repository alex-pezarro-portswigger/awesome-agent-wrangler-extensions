# Contributing

Open a PR adding one line to the README list, in alphabetical order:

```md
- **[repo-name](https://github.com/owner/repo-name)** — One sentence on what it does.
```

The extension must:

- be installable from its git URL (see the [extension docs](https://github.com/PortSwigger/agent-wrangler/blob/main/docs/extensions.md))
- have a README explaining what it does and how to install it
- declare every capability it uses in `requires`
